
## 1. Предметная область

В качестве исходной вселенной взят фандом **«Смешарики»** (smeshariki.fandom.com).
Идея замены: мир мультсериала переосмыслен как **IT-компания**, а персонажи —
как **IT-специалисты**. Сохранены логика и связи мира (кто с кем дружит, где живёт,
чем занимается), но все узнаваемые имена и реалии заменены на профессиональные термины,
чтобы базу нельзя было «угадать» по памяти модели.

Соответствие персонажей профессиям:

| Смешарик | IT-роль |
|----------|---------|
| Крош | джавист |
| Ёжик | гошник |
| Нюша | системный аналитик |
| Бараш | скрам-мастер |
| Лосяш | архитектор |
| Копатыч | девопс |
| Кар-Карыч | продакт |
| Совунья | бухгалтер |
| Пин | тимлид |
| Биби | автотестер |
| Панди | бизнес-аналитик |

Заменены не только персонажи, но и предметы и локации мира:
дом/домик → рабочее место, библиотека → конфлюенс, компьютер → сервер,
ромашковая долина → офис компании, серия → спринт, эпизод → тикет и т.д.

## 2. Скачивание и очистка текстов

Исходные страницы фандома скачаны и очищены от HTML и лишнего форматирования,
разбиты по сущностям (один файл — одна сущность: персонаж, локация или эпизод).
Результат — **32 документа** в формате `.md` в папке исходников.

- Исходные (очищенные) тексты: [`smeshariki-fandom/`](smeshariki-fandom/)

## 3. Замена ключевых терминов

Собраны два словаря соответствий «исходное → вымышленное»:

- [`terms_map.json`](terms_map.json) — базовые термины: персонажи, предметы, локации (54 пары).
- [`terms_series_map.json`](terms_series_map.json) — названия серий, эпизодов и цитат (186 пар).

Замена выполняется скриптом:

- [`replace_terms.py`](replace_terms.py) — копирует файлы из `smeshariki-fandom/`
  в `knowledge_base/`, применяя оба словаря к содержимому **и к именам файлов**.

### Логика замены

Скрипт содержит небольшой движок склонения русских существительных, чтобы замены
были грамматически корректными и не оставляли следов исходной вселенной:

1. **Однословный → однословный термин** (`крош → джавист`): склоняются оба слова и
   сопоставляются по падежам — `Кроша → Джависта`, `Крошем → Джавистом`.
2. **Однословный → многословный термин** (`дом → рабочее место`,
   `нюша → системный аналитик`): все падежные формы исходного слова заменяются на
   базовую форму цели. Падежные окончания к многословной цели не добавляются —
   это исключает «мусор» вида `рабочее местоа`.
3. **Многословные / составные / в кавычках** (названия серий, `кар-карыч`,
   `пин-код`): точное совпадение без склонения.
4. **Притяжательные прилагательные** от имён (`Нюшин → системного аналитика`).
5. **Регистр сохраняется**: если исходное слово с заглавной буквы, замена тоже
   получает заглавную.

Поиск идёт по границам слов (Cyrillic/Latin), от самых длинных терминов к коротким,
чтобы избежать частичных замен.

## 4. Финальная база

- Готовая база знаний: [`knowledge_base/`](knowledge_base/) — **32 переименованных
  и очищенных документа** `.md`.


### Как воспроизвести

```bash
python3 replace_terms.py
```

Скрипт прочитает `smeshariki-fandom/`, применит `terms_map.json` и
`terms_series_map.json` и перезапишет содержимое `knowledge_base/`.
